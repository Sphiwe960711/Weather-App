This is a simple weather application that provides real-time weather information such as temperature, wind speed, humidity, and overall weather condition.

 The app uses the OpenWeather API to fetch data and is built using HTML, CSS, and JavaScript.

Features:

Temperature: Displays the current temperature in the selected location.
Wind Speed: Shows the current wind speed.
Humidity: Displays the current humidity percentage.
Weather Condition: Shows the current weather (e.g., sunny, cloudy, rainy, etc.)

Tech Stack
HTML: Structure of the web page.
CSS: Styling and layout of the application.
JavaScript: Fetching data from the OpenWeather API and dynamic updates
